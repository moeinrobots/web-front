# وب‌ساز — فرانت‌اند

فرانت‌اند وب‌سایت وب‌ساز با Next.js، React و TypeScript پیاده‌سازی شده است. صفحه اصلی، خدمات، تعرفه‌ها، نمونه‌کارها، بلاگ، درباره ما، تماس و پنل مدیریت در این پروژه قرار دارند.

## اجرای محلی

نیازمندی: Node.js نسخه ۲۰ یا جدیدتر.

```bash
npm install
copy .env.example .env.local
npm run dev
```

سایت به‌صورت پیش‌فرض در `http://localhost:3000` اجرا می‌شود.

## متغیرهای محیطی

- `NEXT_PUBLIC_API_URL`: نشانی عمومی API، مانند `https://api.example.com/api`
- `INTERNAL_API_URL`: نشانی API برای درخواست‌های سمت سرور
- `NEXT_PUBLIC_SITE_URL`: نشانی نهایی وب‌سایت

## ساخت نسخه نهایی

```bash
npm run build
npm run start
```

خروجی پروژه به‌صورت standalone تنظیم شده و Dockerfile نیز برای استقرار مستقل آماده است.

## پنل مدیریت

پنل در مسیر `/admin` قرار دارد. اطلاعات ورود از بک‌اند دریافت می‌شود. در این بخش می‌توان درخواست‌های مشتریان و مقاله‌های بلاگ را مدیریت کرد.
